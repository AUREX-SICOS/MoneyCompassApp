# MorisMoney Compass — live competition demo

**Live website:** [https://aurex-sicos.github.io/MoneyCompassApp/](https://aurex-sicos.github.io/MoneyCompassApp/)

This public-only package contains **compiled static demo assets, not the development source or its Git history**. The fictional Maya journey is for demonstration, not financial advice. Official regulator links, MorisMoney warning indicators and fictional community records have different evidentiary status. Do not enter real banking credentials, PINs, OTPs, passwords or real reports.

The website runs without a server API; experimental local AI is not offered on the public site. Browser data stays local to the visitor's browser, subject to that browser's storage behavior.

## About this repository

This repository contains the publicly deployed compiled demo, not the private development source. Future updates must be rebuilt in the private development checkout, checked for sensitive assets, and copied into `site/` for review. This repository is not a source build environment.
