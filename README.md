# MorisMoney Compass — compiled competition demo

**Website:** [https://aurex-sicos.github.io/MoneyCompassApp/](https://aurex-sicos.github.io/MoneyCompassApp/) (intended address; not published by this preparation package).

This public-only package contains **compiled static demo assets, not the development source or its Git history**. The fictional Maya journey is for demonstration, not financial advice. Official regulator links, MorisMoney warning indicators and fictional community records have different evidentiary status. Do not enter real banking credentials, PINs, OTPs, passwords or real reports.

The website runs without a server API; experimental local AI is not offered on the public site. Browser data stays local to the visitor's browser, subject to that browser's storage behavior.

## Publication — owner approval required

Only after separately reviewing and approving the private-to-public repository migration, create a **new** `AUREX-SICOS/MoneyCompassApp` public repository with a fresh history containing only this package. Do not reuse, mirror, import or push the private development repository's history. Configure Pages source to **GitHub Actions**, then manually run the included `Deploy compiled demo` workflow. Verify the live site and repository anonymously before sharing the link or relying on the presentation QR.

Future updates must be rebuilt in the private development checkout, checked for sensitive assets, and copied into `site/` for a new review. This repository is not a source build environment.
